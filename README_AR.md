# الموجّهة الطلابية — النسخة الثانية (Firebase تجريبي)

**التحديث: ٢٥ أكتوبر ٢٠٢٦** — المصدر البرمجي الجديد مستقل تمامًا عن المستودع القديم `student-guidance`.

## الخيار النهائي للمزامنة

اختير **Firebase Authentication + Cloud Firestore**؛ لا نستخدم Tailscale أو كمبيوتر المنزل كخادم أو Supabase. أربع أجهزة للمستخدمة نفسها: جوالان وكمبيوتران. لا تحتاج إلى كمبيوتر مفتوح طوال الوقت.

- `firebase-sync.js`: مصادقة Firebase، تحديثات لحظية عبر Firestore ورفع طابور التعديلات التجريبية.
- `firestore.rules`: لا تعمل صلاحيات القراءة والكتابة حتى وضع UID المستخدم التجريبي المحدد ونشر القواعد.
- `config.js`: لا توجد بيانات مشروع Firebase بعد. إعدادات Web العامة اللازمة لربط المشروع فارغة.
- `app.js`: تطبيق تجريبي مستقل يعرض المدرستين `p31` و`m34`، وملفات الطالبات والمهام والمواقف والتقارير.
- `migration.html` و `migration.js`: فحص محلي لنسخة JSON القديمة وتوزيع السجلات بين المدرستين، **النقل السحابي الحقيقي معطل**.

**[README_FIREBASE_AR.md](README_FIREBASE_AR.md)**: جميع خطوات إنشاء مشروع Firebase بنظام Spark المجاني، وإعداد البريد التجريبي وقواعد Firestore وبيانات الربط وتفاصيل اختبار الأجهزة الأربعة.

## سلامة بيانات الطالبات

- **لا ترفع أي سجل حقيقي إلى Firebase أو GitHub الآن.** المشروع التجريبي لا يملك موافقة الجهة المعنية على الاستضافة والتخزين الخارجي.
- البيانات المرسلة في محادثة سابقة خاصة بالمدارس لا توجد داخل هذا المستودع ولا ضمن ملفات التجربة.
- SQLite / Tailscale / Supabase لم تعد جزءًا من المسار المعتمد؛ بقي `cloud.js` وملفا `supabase-*.sql` كأرشيف كود قديم غير مستخدم ويمكن إزالتها لاحقًا بعد التأكد من عدم الحاجة إليها.
- GitHub Pages صالح لتجربة بيانات وهمية فقط. لا تضع بيانات الطالبات على صفحات مشتركة الأصل أو في `localStorage` / IndexedDB غير مشفر.
- لا يُفترض أن قواعد Firebase تحل وحدها اشتراطات الموافقات التنظيمية والتشفير المحلي وإدارة النسخ الاحتياطية؛ الإنتاج يحتاج مراجعة مستقلة.
- لا تكتب كلمات المرور أو مفاتيح `service account` داخل `config.js` أو الرسائل.

## الوظائف الحالية

- الواجهة الكحلية والذهبية، والمدرستان منفصلتان في الفلاتر وعرض السجلات.
- إنشاء/تعديل ملف طالبات تجريبي ومواقف ومهام.
- معاينة وطباعة تقارير، تصدير JSON وCSV للتجربة.
- المزامنة الفورية تستلزم ربط مشروع Firebase، إنشاء مستخدم تجريبي واحد وإعداد `firestore.rules`.
- معالجة تعديلين متعارضين تتم حاليًا برفض التحديث المختلف والاحتفاظ به محليًا، لكن شاشة الدمج التفصيلية قيد التطوير.
- النسخ الاحتياطي الآلي والاستعادة، والتحقق من تشفير البيانات على الأجهزة الأربعة، وتعميم استخدام البيانات الحقيقية غير مكتملة بعد.
